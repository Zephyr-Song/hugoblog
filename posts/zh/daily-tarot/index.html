我做了一个微信小程序：每日牌阵

高中时用塔罗牌给同学测过，觉得挺准的。后来自己写了个小程序，把这件事自动化了。
2026年4月3日 · Zephyr
目录
  • 开发过程
  • 一些感想

清明打算去威海、烟台、青岛玩一趟。

就想着做点什么有意思的东西。突然想起之前玩过的塔罗牌——那时候觉得挺准的，就是每次查资料太麻烦了。 其实我不太信"神秘学"。但我信一件事：有时候，随机本身就是一种信息。

你随机抽一张牌，牌面和你当下的处境产生某种共鸣，这件事本身就很有意思。

17岁生日有人送了我一副塔罗牌，那时候下课无聊，我经常给同学"测一测"。没有系统学过，就是拿着说明书对着看。但奇怪的是，同学普遍觉得挺准的——当然，“准"可能更多是心理暗示的作用。

测完同学会说"真的诶，我最近确实是这样”，或者"这个建议还挺有道理的"。我也不知道是真的准，还是人总能从模糊的描述里找到和自己相关的部分。

但那个感觉，我一直记得。

开发过程#

用的是微信小程序，这个没什么犹豫的——微信生态用起来最顺手，而且塔罗这东西在年轻人里挺流行的，微信小程序传播也方便。

第一步：牌库

塔罗78张牌，每张需要存储：名称、关键词、正位解读、逆位解读、对应元素、数字符号。数据量不大，用 JSON 存着就行。

主要的工作量在解读文本上。78张牌每张都要有至少一套解读，不能太水，也不能写得像百度百科。我参考了几本书的解读，自己改写成更口语、更贴近当代年轻人生活的版本。

比如"女祭司"，经典解读是"直觉、神秘、内在智慧"，我写的是：

她坐在两根柱子之间，眼帘低垂，不说话。她知道很多事情，但她选择不说。这个阶段适合向内看，而不是向外找答案。适合独处、冥想、写日记。不适合做重大决定。

听起来还挺像那么回事的。

第二步：随机抽牌逻辑

每天一抽，关键是不能重复——抽过的牌今天不能再抽，第二天重置。

实现其实很简单：用 localStorage 存一个日期和当天的牌组，每天打开时判断一下日期是否变化就行。

第三步：界面

配色选了有点神秘感的深紫。

最麻烦的是"翻牌"的动画。微信小程序的动画 API 有限制，做不出很炫的效果，最后用了一个简单的2D翻转，low是low了点，但够用了。

第四步：分享

小程序有个"发送给朋友"的功能，可以把今天的牌阵生成一张图分享出去。我加了自定义文字——“今日牌阵 · 第X抽”，有点仪式感。

一些感想#

这个小程序很简单，没什么技术含量。但它让我重新审视了一件事：有些东西的价值，不在于复杂度，而在于它恰好出现在某个时刻。

塔罗牌本身可能没什么道理，但"每天停下来，想一想自己正在经历什么"这件事本身，是有意义的。

现代人太忙了，忙到没有时间和自己对话。抽一张牌，看看解读，然后想一想——这可能比刷两小时短视频要有用一点。

我不知道这个小程序能走多远。也许就几十个人用，也许哪天就被微信下架了。但做这件事的过程本身，让我挺开心的。

下一次，我想给它加一个功能：根据抽到的牌，生成一首适合当下听的歌。歌单我已经想好了。

做成那天，我抽到了愚者——大阿尔卡纳的第零张。不知道有何暗示。
