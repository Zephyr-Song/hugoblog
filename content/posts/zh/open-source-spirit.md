我是从什么时候开始喜欢开源的？

大概是某一天，我在 GitHub 上找到了一个项目，它解决了我一直头疼的问题，代码写得很漂亮，README 写得很清楚，而且完全免费。

点开作者主页，是个不知道哪个国家的人，头像是一只猫。

一个陌生人，写了一段代码，放在网上，让全世界的人都能用。没有任何商业目的。

我觉得这件事挺了不起的。

## 开源是什么

从技术上说，开源（Open Source）就是把源代码公开，允许任何人查看、使用、修改、分发。

但我更愿意从更广的角度来理解它：**开源是一种「共享默认值」的文化**。

这和我们熟悉的商业逻辑刚好相反。商业逻辑的默认值是：我的东西是我的，你要用就付钱。开源的默认值是：我做的东西是公开的，你可以拿去用，如果你改进了，最好也公开出来。

这不是说开源反对商业，很多开源项目有商业支持，很多公司靠开源赚钱。而是说**在开源文化里，知识和工具的流动是默认被鼓励的**。

## 站在巨人的肩膀上

我用这个博客写文章，它是用 Hugo 构建的——开源的。主题是 PaperMod——开源的。部署在 GitHub Pages 上——平台是商业的，但背后用的 Git 是开源的。我写代码用的 VS Code——开源的。

往上追溯，我用的操作系统底层用了 Linux 内核的大量代码。Linux 是开源的，而且是有史以来最成功的开源项目之一，全球超过 90% 的服务器在跑它。

我们每天享用的数字基础设施，有相当大一部分是靠全球无数开发者在业余时间贡献代码搭建起来的。

这件事想想真的很神奇。

## 开源让我印象最深的几件事

**Linus Torvalds 的一封邮件**  
1991 年，芬兰赫尔辛基大学的一个学生在新闻组上发了一封邮件，说自己在写一个"业余爱好"操作系统，问有没有人感兴趣。那个学生叫 Linus Torvalds，那个系统叫 Linux。

三十多年后，它跑在了世界上大多数的服务器、超算、Android 手机上。

**Wikipedia**  
一个没有广告、不追求盈利、靠全球志愿者维护的百科全书，成为了人类历史上最大的知识库之一。每次我在上面找到需要的信息，都会想：这是人类协作的奇迹。

**疫情期间的开放数据**  
COVID-19 期间，大量研究人员选择在预印本平台（arXiv、bioRxiv）上发布研究，跳过了漫长的同行评审流程，让全球科学界能实时共享信息。疫苗的研发速度，部分得益于这种开放的知识共享文化。

## 一些思考

开源不是万能药。它也有问题：

- 很多核心开源项目靠少数几个人维护，他们精疲力竭、收入微薄
- 开放代码也意味着安全漏洞可能更容易被发现和利用
- 商业公司有时候"白嫖"开源成果，却不回馈社区

但这些问题不改变我对开源精神的欣赏。

在一个越来越封闭、越来越数据垄断的互联网时代，开源是一种难得的反向力量。它告诉我们：知识是可以共享的，协作是可以跨越边界的，一个不认识的人写的代码，可以让全世界受益。

这是互联网最初的精神，也是我希望它不要失去的东西。

## 我能做什么

我现在还是个学生，写的代码也不多，但我尝试把自己做的小东西放在 GitHub 上公开。哪怕只有几个星，也挺开心的。

从消费者变成贡献者，哪怕是很小的贡献——我觉得这是对开源文化最好的致敬。
